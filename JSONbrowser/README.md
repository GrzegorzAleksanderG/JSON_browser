- opis podjętych decyzji architektonicznych:
jest to prosta aplikacja webowa, zbudowana z użyciem vite, style zostały dodane przy użyciu narzędzi AI,
styl graficzny przypomina Dribble, jako UI wykorzystano gotowe elementy biblioteki Lucide.

- co zostałoby zrobione przy większej ilości czasu:
np. podgląd wybranego pliku, jego modyfikacja, tworzenie struktury folderów i plików na podstawie przesłanego JSONa.

- znane ograniczenia:
na mniejszych ekranach przy dużym zagnieżdżeniu pełna ścieżka może nie być widoczna.
